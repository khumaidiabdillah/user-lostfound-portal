# Portal Publik - Laporan Barang Hilang & Temuan

Portal publik terintegrasi posko keamanan untuk pelaporan masyarakat kehilangan barang atau penemuan barang.

## ✨ Fitur Utama
- **Landing Feed & Real-Time Search**: Pencarian cepat nama barang, lokasi, dan filter pills kategori.
- **Formulir Laporan Publik**: Pilihan jenis kehilangan/temuan, upload foto barang, titik lokasi, dan kontak WhatsApp.
- **Detail Laporan & Integrasi WhatsApp**: Tombol direct chat WhatsApp ke pelapor/penemu.

## 🛠️ Tech Stack
- Next.js 15 (App Router, TypeScript)
- Tailwind CSS
- Supabase JS Client & Storage

## 🚀 Menjalankan Project
```bash
npm install
npm run dev
```
Buka browser di `http://localhost:3004`.
